# Quantisierung als Eigenwertproblem (Erste Mitteilung)

*Skeleton bib note.* The first of Schrödinger's four 1926 papers founding wave mechanics. Quantises hydrogen by treating it as an eigenvalue problem for a differential operator acting on $\psi$; the time-independent Schrödinger equation $H\psi = E\psi$. Reproduces the Bohr–Sommerfeld spectrum from a single continuous formalism. Schrödinger himself starts from a *relativistic* wave equation (what we now call Klein–Gordon) but switches to non-relativistic because the relativistic version produces incorrect fine-structure splittings. The dual framework re-derivation via [[FoundationsII-Classical]]'s positive-definite $K$ avoids the negative-energy modes that motivate Schrödinger's retreat.
